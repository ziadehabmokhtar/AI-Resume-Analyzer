# Sample Jobs Knowledge
These are fictional demo job descriptions created for the project. They are not live vacancies.

## Junior Data Analyst
Skills: Python, SQL, pandas, Excel, data analysis, communication.
Typical work: clean data, build reports, create dashboards, explain findings to stakeholders.

## Backend Python Developer
Skills: Python, FastAPI, REST API, SQL, Git, testing.
Typical work: build APIs, validate requests, work with databases, write automated tests.

## Machine Learning Intern
Skills: Python, NumPy, pandas, scikit-learn, machine learning.
Typical work: prepare datasets, train baseline models, evaluate experiments, document results.
