# Skill Descriptions

Python: general-purpose language commonly used for backend development, automation, data analysis and AI.
SQL: language for querying and manipulating relational databases.
FastAPI: Python framework for building typed REST APIs.
Pandas: Python library for tabular data manipulation and analysis.
NumPy: Python library for numerical arrays and scientific computing.
Scikit-learn: Python library for classical machine learning workflows.
Git: version control system used to track source code changes.
REST API: HTTP-based interface organized around resources and standard methods.
Communication: ability to explain technical and business information clearly.
Problem solving: structured approach to identifying and resolving problems.
